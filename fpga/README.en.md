# FPGA: current Quartus project

[Русский](README.md) | **English**

Device: **Cyclone IV E EP4CE6E22C8**. Top level and revision:
`DistanceSensorFpga_v0`. Open this project: [QPF](DistanceSensorFpga_v0.qpf).
HDL, ROM, QSF and SDC sources match the bench's current working project.
There is no FIR. The original early-project archive is not required to build.

## Build

Verified with **Quartus Prime Lite 25.1std, build 1129**, with Cyclone IV support.
Install the tools and device package from the
[official distribution](https://www.altera.com/downloads/fpga-development-tools/quartus-prime-lite-edition-design-software-version-25-1-windows).
Questa is not required to synthesise this project.

Open the QPF and select Start Compilation, or run from `fpga/`:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 -QuartusRoot "D:/altera_lite/25.1std/quartus"
```

The user supplies the path. Instead of the argument, set `QUARTUS_ROOTDIR`
or put `quartus_sh` on PATH. The script builds the project and timing reports;
it neither opens the programmer nor programs the board. Outputs appear in
`output_files/`, with additional reports in `test-results/`.
For other environments, the standard command from this folder is
`quartus_sh --flow compile DistanceSensorFpga_v0` (Linux was not tested here).

## Simulation

Requires Python and [Icarus Verilog](https://steveicarus.github.io/iverilog/),
with `iverilog` and `vvp` from the same installation. From `fpga/`:

```powershell
python tools/test_phase_hdl.py
```

If Icarus is not on PATH: `python tools/test_phase_hdl.py --iverilog "D:/iverilog/bin/iverilog.exe"`.
Nine suites check ADCs, phases, variable IFs and amplitudes, DDS, the digital
phase meter, CDC, UART and the top level. Tests compare 88 pin assignments
against `pin-lock.json`; PLL models use SIMULATION for these runs.
After the variable_phase test, run the independent NumPy least-squares check:

```powershell
../app/.venv/Scripts/python.exe tools/check_variable_phase.py
```

Client integration tests read UART bytes generated by these simulations;
predefined replies do not substitute for current RTL.

## Processing

AD9959 SYSCLK 500 MHz, SYNC_CLK 125 MHz. Eight ADS8681 devices start
synchronously at 250 ksample/s. Analogue channels 1–4 use least-squares
processing over 1000 samples, updated every 250 samples. The digital phase
meter measures 16 edges of each polarity at 125 MHz. Permitted IF is
approximately 1–20 kHz, with a separate IF for each pair. Amplitudes can change
without changing the ideal model phase; that property does not eliminate
noise, clipping or hardware distortion.

ADC5–8: if any detector has |U| <0.5 V, overall validity is cleared.
The beam-loss threshold is 100 ms; the flag recovers automatically with
a good signal. Detailed fields and atomic DDS writes:
[UART v3](../docs/protocol-v3.en.md).
Distance and speed are not yet calculated inside the FPGA.
