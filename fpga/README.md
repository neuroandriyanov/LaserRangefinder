# FPGA: текущий проект Quartus

**Русский** | [English](README.en.md)

Устройство **Cyclone IV E EP4CE6E22C8**. Верхний уровень и ревизия:
`DistanceSensorFpga_v0`. Открываемый проект: [QPF](DistanceSensorFpga_v0.qpf).
Исходники HDL, ROM, QSF и SDC совпадают с текущим рабочим проектом стенда.
FIR отсутствует. Архив исходного раннего проекта для сборки не требуется.

## Сборка

Проверен **Quartus Prime Lite 25.1std, build 1129** с поддержкой Cyclone IV.
Установите инструмент и пакет устройств из
[официального комплекта](https://www.altera.com/downloads/fpga-development-tools/quartus-prime-lite-edition-design-software-version-25-1-windows).
Questa для синтеза этого проекта не требуется.

Откройте QPF и выполните Start Compilation либо из каталога `fpga/`:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 -QuartusRoot "D:/altera_lite/25.1std/quartus"
```

Путь указывает пользователь. Вместо параметра можно задать `QUARTUS_ROOTDIR`
или добавить `quartus_sh` в PATH. Скрипт собирает проект и отчёты таймингов,
не открывает программатор и не записывает плату.
Результаты появляются в `output_files/`, дополнительные отчёты — в `test-results/`.
Для других сред стандартная команда из этой папки:
`quartus_sh --flow compile DistanceSensorFpga_v0` (Linux здесь не проверялся).

## Моделирование

Нужны Python и [Icarus Verilog](https://steveicarus.github.io/iverilog/),
`iverilog` и `vvp` из одной установки. Из каталога `fpga/`:

```powershell
python tools/test_phase_hdl.py
```

Если Icarus отсутствует в PATH: `python tools/test_phase_hdl.py --iverilog "D:/iverilog/bin/iverilog.exe"`.
Девять наборов проверяют АЦП, фазы, переменные ПЧ и амплитуды, DDS,
цифровой фазомер, CDC, UART и верхний уровень. Тесты сверяют 88 назначений
выводов с `pin-lock.json`; модели PLL для этой симуляции используют SIMULATION.
После теста variable_phase независимая проверка NumPy-МНК:

```powershell
../app/.venv/Scripts/python.exe tools/check_variable_phase.py
```

Интеграционные тесты клиента читают UART-байты, полученные из этих симуляций;
готовые ответы не подменяют актуальный RTL.

## Обработка

AD9959 SYSCLK 500 МГц, SYNC_CLK 125 МГц. Восемь ADS8681 запускаются синхронно,
250 квыб/с. Аналоговые каналы 1–4 обрабатываются МНК на 1000 отсчётов,
обновление каждые 250 отсчётов. Цифровой фазомер измеряет 16 фронтов каждой
полярности на 125 МГц. Допустимая ПЧ примерно 1–20 кГц, каждая пара имеет
свою ПЧ. Амплитуды меняются без изменения идеальной фазы модели; шум,
ограничение и аппаратные искажения этим свойством не устраняются.

ADC5–8: при |U| <0,5 В на любом детекторе общая пригодность снимается.
Порог потери луча 100 мс; флаг автоматически восстанавливается при хорошем
сигнале. Подробные поля и атомарная запись DDS: [UART v3](../docs/protocol-v3.md).
Расстояние и скорость внутри FPGA пока не вычисляются.
