# Приложение LaserRangefinder 0.5.1

**Русский** | [English](README.en.md)

Русский интерфейс: измерения FPGA, графики, Vector60, запись калибровки,
расстояние по аналоговым фазам, настройка четырёх DDS и чтение реального банка.
Исходники в `desktop_app/`, клиент протокола и рулетки — в `tools/`.

## Установка и запуск

Проверенная среда — Windows, Python 3.14 x64 с Tcl/Tk. Зависимости требуют
Python ≥3.12; другие версии ОС и Python в этом комплекте не проверялись.
Python устанавливается отдельно: [официальные загрузки](https://www.python.org/downloads/windows/).
Приложению не нужны Quartus, осциллограф или рулетка для просмотра демонстрации.

Из этого каталога:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
.\Run.cmd --demo
```

Если Python не в PATH, укажите путь к своему интерпретатору:
`powershell -ExecutionPolicy Bypass -File install.ps1 -Python "D:/Python/python.exe"`.
Установщик создаёт локальную `.venv`, не изменяет системные Python-пакеты.
Эквивалентные ручные команды:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m desktop_app --demo
```

Для работы с платой запустите `Run.cmd` без `--demo`.
В «Настройки» выберите свой порт. USB–TTL должен иметь уровни 3,3 В;
электрический RS-232 ±12 В к X5 напрямую не подключается.
Формат по умолчанию 115200, 8N1. Период запроса 10 мс — целевое значение;
реальная скорость ограничена ответом 112 байт и последовательным обменом.
Порт не открывается автоматически при запуске приложения.

## Настройки, данные и DDS

Настройки сохраняются в `%LOCALAPPDATA%/LaserRangefinder/settings.json`,
то есть в профиле текущего пользователя. Для изолированного запуска можно
передать `--settings путь/settings.json` и `--capture-dir путь/журналы`.
Демонстрация использует отдельные настройки. Папка `captures/` создаётся
при записи; журналы содержат первичные данные и не включаются в Git автоматически.

COM-порт и адрес рулетки при первом запуске пустые. Сохраняются периоды,
тайм-ауты, графики и редактируемый профиль DDS. Файл профиля с точными FTW:
[default.json](profiles/dds/default.json). Он соответствует стартовым значениям FPGA:

| Выход | Частота, МГц | ASF | Фаза |
|---|---:|---:|---:|
| CH0 — НЧ лазер | 1,495361328125 | 200 | 0° |
| CH1 — ВЧ гетеродин | 74,027135735378 | 1000 | 0° |
| CH2 — НЧ гетеродин | 1,499361358583 | 1000 | 0° |
| CH3 — ВЧ лазер | 74,020385742188 | 450 | 0° |

ПЧ НЧ 4000,030458 Гц; ВЧ 6749,993190 Гц. Поля ПЧ на вкладке DDS доступны
только для чтения. «Отправить в FPGA» проверяет значения, передаёт банк и
выполняет единый COMMIT; затем считывает банк обратно. Сохранение на ПК само
по себе не изменяет плату. После reset FPGA возвращается к аппаратным defaults.
Профиль подобран на одном стенде при 1642 мм; он не является универсальным оптимумом.

## Рулетка Vector60

Необязательная часть. Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-vector60.txt
```

Используется отдельный Bluetooth USB-адаптер с WinUSB и стек Bumble.
Проверен ASUS USB-BT400, VID:PID `0B05:1D70`; другие адаптеры не проверены.
Обычного сопряжения через Bluetooth Windows для этого backend недостаточно.
Драйвер настраивается отдельно по [документации Bumble для Windows](https://google.github.io/bumble/platforms/windows.html).
Используйте выделенный адаптер: WinUSB не заменяет системный Bluetooth-стек
для клавиатур и других устройств. Программа сама драйверы не устанавливает.
Экспериментальный UsbDk backend исключён.

Сканирование после настройки адаптера:

```powershell
.\.venv\Scripts\python.exe tools/vector60_winusb.py scan --usb-transport usb:0B05:1D70
```

Введите обнаруженный Bluetooth-адрес в настройках программы; при необходимости
измените USB VID:PID. Отметьте подключение рулетки и отдельно запустите опрос.
Запросы не накладываются друг на друга, тайм-аут по умолчанию 3 с, после него
цикл запускается заново. В графике доступны расстояние и ось X в мм.

## Калибровка

Неподвижная точка принимается после **трёх одинаковых отсчётов рулетки**,
при наличии подходящих свежих фаз. Звуковой сигнал подтверждает запись.
Повтор той же дистанции не добавляется. Кнопка расчёта сохраняет модель;
для её применения проверяются происхождение данных и соответствие банка DDS.
Чужая cal2 не активируется автоматически на другой плате.

Пример cal2 включён для воспроизведения анализа и тестов, а не как общая
калибровка всех экземпляров. НЧ выбирает оборот ВЧ, полином четвёртой степени
вычисляет расстояние по развёрнутой ВЧ-фазе. Вне проверенного диапазона результат
не выдаётся. Изменение частот/аналогового тракта требует новой калибровки.

## Проверки без приборов

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s desktop_app -t . -p "test*.py"
```

Для полного набора нужны `requirements-vector60.txt` и рабочий Tcl/Tk.
Тесты используют временные настройки и имитаторы устройств, не COM/Bluetooth.
Протокольные тесты в `tools/` дополнительно требуют предварительного запуска
[HDL-моделирования](../fpga/README.md#моделирование):

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tools -p "test*.py"
```

Зависимости верхнего уровня закреплены в requirements. Полный список пакетов
проверенного окружения: [snapshot](../docs/verification/python-packages.txt).
