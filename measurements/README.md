# Стендовые измерения

**Русский** | [English](README.en.md)

Последняя актуальная серия — [3 ноября 2026 года](2026-11-03/README.md):
10 положений мишени, 762–5635 мм, показания Vector60, фазы и амплитуды FPGA,
две осциллограммы на точку, Excel с формулами расстояния и ошибки.

Каждая серия хранится в отдельном каталоге даты. Коэффициенты, диагностика,
условия отбора, ограничения и происхождение данных описаны внутри серии.
Новые результаты добавляются рядом, а не поверх старых.

Английская версия последней серии доступна в [отчёте](2026-11-03/README.en.md)
и [галерее осциллограмм](2026-11-03/Осциллограммы/README.en.md).
Оригинальные исторические README включены в манифест серии и не изменяются
даже ради языковой ссылки; переключение доступно на этой странице и в
английских копиях. Служебные имена `Данные` и `Осциллограммы` сохранены
для совместимости путей. Значение `н/д` в исходном JSON означает «нет данных»;
в английской таблице оно показано как `n/a`.
