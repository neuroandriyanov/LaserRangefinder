# Bench measurements

[Русский](README.md) | **English**

The latest current series is [3 November 2026](2026-11-03/README.en.md):
10 target positions, 762–5635 mm, Vector60 readings, FPGA phases and
amplitudes, two oscilloscope captures per point, and Excel with distance
and error formulas.

Each series is kept in a separate dated folder. Coefficients, diagnostics,
selection criteria, limitations and data provenance are described within
the series. New results are added alongside old ones, not over them.

The latest series has an English [report](2026-11-03/README.en.md)
and [oscilloscope gallery](2026-11-03/Осциллограммы/README.en.md).
The original historical READMEs are covered by the series manifest and
are not changed even to add a language link; use this page or the English
copies to switch languages. The literal directory names `Данные` (Data)
and `Осциллограммы` (Oscilloscope captures) are retained for path compatibility.
The original JSON value `н/д` means “not available”; the English workbook
displays it as `n/a`.
