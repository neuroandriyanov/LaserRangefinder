# Журнал проекта для продолжения работы

Это компактная история самостоятельного комплекта. Подробная переписка и полные
первичные сеансы остаются у автора; важные данные, решения и ограничения
собраны здесь и в [памятке ИИ](AI_HANDOFF.md).

## 1–3 ноября 2026, Samara (UTC+4): фазомеры и работа со стендом

Поэтапно добавлены синхронное чтение восьми АЦП, расчёт аналоговых фаз,
цифровой фазомер, контроль пригодности и запросы измерений через UART.
Сравнивались сигналы осциллографа, ответы FPGA и расстояния Vector60 при
ручном перемещении мишени с остановками. Отдельно исследовались задержки рулетки.

Приложение получило настройку порта, графики, запись точек калибровки и DDS.
В протоколе v3 банк DDS применяется единым обновлением, фазомеры работают
с разными ПЧ. FIR после отсутствия заметного улучшения по наблюдениям автора
убран. Подбор частот/амплитуд при 1642 мм дал текущий профиль около 4/6,75 кГц.
Причина редких скачков фазы пока не доказана.

## 3 ноября 2026, Samara (UTC+4): cal2 и независимая серия

Cal2 содержит 21 точку на 638–5583 мм. Выбран расчёт по развёрнутой ВЧ-фазе
нормированным полиномом четвёртой степени; НЧ служит для выбора оборота.
Затем выполнена самостоятельная проверка на десяти расстояниях 762–5635 мм
без подгонки коэффициентов. Сохранены Excel, две осциллограммы на точку,
средние, разброс и диагностика.

На девяти точках внутри области модели RMS расхождения с Vector60 —
13,36/13,16 мм. Последняя точка вне cal2; зарегистрирован запоминаемый
цифровой флаг diagnostics=4. Причина не установлена, ошибки и неудачные
попытки сохранены. [Полный отчёт серии](../measurements/2026-11-03/README.md).

## 3 ноября 2026, 22:13 Samara (UTC+4): переносимый комплект

Подготовлены приложение 0.5.1, текущий проект Quartus, схемы, фотографии
и последняя серия. Убраны личные COM/MAC из defaults копии, добавлен выбор
VID:PID адаптера и самостоятельные инструкции. Рабочие исходники стенда
и исходная серия не изменены.

Чистая установка, перенос в путь с пробелами и демозапуск проверены.
Прошли 63 теста приложения, 22 протокола и 9 HDL-наборов. Контрольный Quartus
compile дал POF, совпадающий с образом стенда; min slack +0,137 нс,
unconstrained 0. [Отчёт](build-verification.md). Плата на этом этапе не записывалась.

## 3 ноября 2026, Samara (UTC+4): история, работа с ИИ и лицензии

По поручению автора основное README оформлено как обзор проекта для GitHub
и будущего сайта. Добавлены история восстановления LE-200 PROFIBUS, описание
стенда, карта экспериментов, галерея и ссылки на FerroDSP и PropValve-RE06MT.
Автор уточнил маркировку PIN-фотодиодов: BPX65. IP68 и 100–200 м обозначены
как направления дальнейшей проверки, а не результаты выполненных испытаний.

Созданы AGENTS.md, START_WITH_AI.md, AI_HANDOFF.md и этот журнал. Памятка
объясняет, что читать, где находится код и как сохранить контекст следующему ИИ.
По лицензиям существующих репозиториев добавлены MIT и CERN-OHL-P-2.0;
область действия описана в NOTICE.md, источники зафиксированы по Git blob SHA.

Проверены 224 внутренние ссылки, 20 путей каталога сайта и контрольные суммы
187 файлов комплекта (без самого корневого manifest). Полные тексты лицензий
побайтово совпали с прочитанными файлами FerroDSP по Git blob SHA.
Приложение, RTL, прошивка, фото и исторические измерения не изменены;
пересборка и новый аппаратный опыт не проводились. Следующий шаг — поручение
автора о публикации либо выбранный технический эксперимент.

## 3 ноября 2026, Samara (UTC+4): первый выпуск в GitHub

Автор создал [LaserRangefinder](https://github.com/neuroandriyanov/LaserRangefinder)
и поручил загрузить комплект и выполнить merge. Для публикации подготовлена
отдельная ветка от начального main; первоначальный README сохраняется
в истории Git. В корень переносится содержимое самостоятельного комплекта,
без дополнительной папки-обёртки и рабочих архивов автора.

Проверяются точный список файлов, SHA256, ссылки и совпадение Git blobs
с локальными файлами. Сборка и тесты кода относятся к сохранённой версии
из build-verification.md; изменение этого этапа — публикация материалов.
Результат слияния и точные SHA фиксируются историей pull request.
