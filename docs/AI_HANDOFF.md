## Что здесь есть

Приложение ПК 0.5.1, FPGA UART v3, схемы, фото и последняя серия измерений.
История: оптика и приёмный блок от неисправного LE-200 PROFIBUS; PIN-фотодиоды
заменены на BPX65, лазерный диод на QL67D7SA. Это сведения автора, записанные
при подготовке описания. Основная плата — собственная разработка.
Подробнее: [история](project-story.md), [стенд](stand.md).

## Актуальная реализация

| Узел | Состояние |
|---|---|
| FPGA | EP4CE6E22C8, проект DistanceSensorFpga_v0 в fpga/ |
| DDS | AD9959, SYSCLK 500 МГц, единый IO_UPDATE, 4 канала |
| АЦП | 8 ADS8681, синхронные 250 квыб/с |
| Аналоговая фаза | МНК/CORDIC, окно 1000 отсчётов, обновление через 250; FIR отсутствует |
| Цифровая фаза | 125 МГц, 16 фронтов каждой полярности |
| Достоверность | Помимо фаз, проверяется модуль U ≥0,5 В на каждом ADC5–8 |
| UART | v3, 115200 8N1, запрос 12 байт, измерения 112, банк DDS 48 |
| Расстояние | Вычисляет ПК по cal2; в FPGA расчёта расстояния и скорости нет |
| Рулетка | Vector60 через отдельный WinUSB Bluetooth-адаптер; не обязательна для FPGA/демо |

Стартовый банк: FTW `[12845056, 635888254, 12879416, 635830272]`,
ASF `[200, 1000, 1000, 450]`, POW все 0. Точная копия —
[default.json](../app/profiles/dds/default.json). ПЧ НЧ 4000,030458 Гц,
ВЧ 6749,993190 Гц. НЧ DDS CH0/CH2, ВЧ CH1/CH3; фазовые пары входов
3−1 ВЧ и 4−2 НЧ. Настройки через COM действуют до reset; на ПК сохраняются отдельно.

## Незакрытые вопросы

- В точке 5635 мм появился `diagnostics=4`: запоминаемое цифровое переполнение.
  Источник — digital_phase_meter.overflow_seen и/или bridge.overrun; какой именно
  и почему, пока не установлено. После восстановления текущий valid может быть 1.
- Причина редких аппаратных скачков фазы не доказана. Проверка DDS не обнаружила
  периодических обновлений при неизменном задании. FIR был убран после отсутствия
  заметного улучшения по наблюдениям автора.
- Подбор DDS проводился в одной точке 1642 мм. Профиль не универсальная калибровка.
- Нужны исследования динамики и температуры, длинная дистанция 100–200 м,
  дальнейший расчёт расстояния/скорости. Комнатные опыты их не заменяют.
- IP68 — цель выбора корпуса; протокола испытаний собранного изделия нет.

Последнее подтверждённое состояние авторского стенда после серии: прежний
DDS-банк, generation=0, diagnostics=4, COM/BLE освобождены, осциллограф RUN,
все четыре канала, 50 мкс/дел. При подготовке этой документации приборы не
опрашивались. Для другого стенда или нового дня состояние нужно узнать заново.

## С чего продолжать

Для изучения достаточно [инструкции](START_WITH_AI.md), демонстрации и сохранённых
данных. Для разработки выберите задачу пользователя, затем соответствующие тесты.
Для bit2 сначала нужен воспроизводимый сценарий и локализация источника;
не сбрасывайте и не скрывайте флаг ради красивой статистики. Для нового стенда
сначала подтвердите подключения, реальный банк и пригодность своей калибровки.

Новые сведения записывайте сюда, завершённые этапы — в [PROJECT_LOG.md](PROJECT_LOG.md).
Исходные данные и старые манифесты сохраняйте. Лицензии уже выбраны по поручению
автора: MIT и CERN-OHL-P-2.0, область — [NOTICE.md](../NOTICE.md).
