# Материалы для ссылок с сайта

**Русский** | [English](website-links.en.md)

Все пути отсчитываются от корня этой папки. Машиночитаемый каталог:
[site-links.json](../site-links.json). Ссылки относительные, поэтому адрес
будущего GitHub-репозитория и домен сайта не зашиты в документы.

После выбора репозитория для просмотра используйте его обычную ссылку на
файл/каталог; для скачивания — URL исходного файла, предоставленный GitHub.
Пробелы и кириллицу кодируйте по сегментам URL (например, пробел → `%20`).
Для воспроизводимых публикаций фиксируйте commit/tag, а не изменяемую ветку.
`measurements/2026-11-03/` — постоянный адрес именно этой серии; новые серии
следует добавлять рядом, не перезаписывая исторические материалы.

На снимках SVG есть внешняя подпись расстояния и пары каналов; рядом лежат
нативные PNG. Для сайта можно ссылаться на SVG или PNG без повторного
скриншота и изменения измерительных следов. Схемы PDF и таблицы XLSX
доступны отдельными файлами. Фото плат полноразмерные, поэтому страница
сайта может задавать уменьшенную ширину отображения и ссылку на оригинал.

Для страницы проекта можно использовать разделы основного README: история,
работа с ИИ, измерения и другие проекты. Подробные статьи имеют собственные
постоянные пути; материалы измерений остаются в каталоге своей даты.
