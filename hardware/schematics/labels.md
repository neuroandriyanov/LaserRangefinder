# Как читать схемы и спецификацию

**Русский** | [English](labels.en.md)

Проверены визуально все восемь страниц [main.pdf](main.pdf) и единственная
страница [power.pdf](power.pdf). Поля основной надписи, имена цепей,
обозначения выводов и компонентов уже набраны на английском или латиницей.
Русских пояснительных надписей, требующих замены внутри схем, не обнаружено.
Поэтому английская версия использует исходные PDF без изменения соединений,
номиналов и графики. Это пояснение к чтению, а не новая редакция схемы.

Редактируемые исходники EDA в этом комплекте отсутствуют. Автоматическое
извлечение текста из этих PDF почти пустое: элементы следует рассматривать
визуально. Номер ниже — номер страницы PDF; поля Sheet в основной надписи
не являются сквозной нумерацией всего файла.

| Страница main.pdf | Что видно на листе |
|---|---|
| 1 | Вход X8, фильтрация и стабилизаторы питания; имена цепей +9V, +5V, +3.3V, +1.8v_ANALOG, +1.8v_DIGIT, +3_CLOCK, PD_OFFSET20V |
| 2 | AD9959, его тактовый источник, четыре выходных тракта с трансформаторами и фильтрами, цепи управления и X2 |
| 3 | Выводы FPGA EP4CE6E22, конфигурационная память, внешняя память, разъёмы и сигналы управления ADC/DDS |
| 4 | Вход X1, стабилизаторы аналогового и цифрового питания, выводы питания FPGA |
| 5 | Аналоговые тракты от X6: усилители, фильтрующие и детекторные узлы, компараторы; связи помечены analog out |
| 6 | Аналоговые тракты от X7, усилители, детекторы, компараторы; контрольные точки X9–X21 |
| 7 | ADS8681 для ADC1–4, интерфейсы ADCPORT, опорные и питающие цепи, индикаторы |
| 8 | ADS8681 для ADC5–8, интерфейсы ADCPORT, опорные и питающие цепи, индикаторы |

На странице power.pdf показаны трансформатор, выпрямительные мосты,
сглаживающие конденсаторы, стабилизаторы и выходной разъём X1. Подписи
In/Out/Gnd означают вход/выход/общий провод. Обозначения цепей и номиналы
оставлены точно как в оригинале; они не являются подтверждением напряжений,
измеренных на собранном стенде.

| Надпись или сокращение | Значение |
|---|---|
| GND | Общий провод |
| IN / OUT | Вход / выход |
| EN, RESET, CS, SCLK, SDI, SDO | Имена функций выводов; активный уровень и требования определяются документацией компонента |
| analog out | Имя группы аналоговых сигналов |
| ADCPORT | Имя группы сигналов интерфейса АЦП |
| DDS | Прямой цифровой синтезатор |
| ADC | Аналого-цифровой преобразователь |
| RevNo / Revision note | Номер / описание изменения |
| Itemref / Quantity | Обозначение позиции / количество |
| Title/Name, designation, material, dimension | Название, обозначение, материал, размер |
| Article No./Reference | Артикул / ссылка |
| Designed by / Checked by / Approved by – date | Разработал / проверил / утвердил — дата |
| File name / Date / Scale / Edition / Sheet | Имя файла / дата / масштаб / редакция / лист |

[bom.xlsx](bom.xlsx) также уже имеет английские заголовки: N — номер,
RefDes — позиционные обозначения, Value — номинал, Name — наименование,
Pcs — количество, Price — цена, SumPrice — сумма. Строки компонентов,
значения, формулы и форматирование оставлены исходными. Слово «Листы»
в служебных метаданных Excel не является заголовком или данными таблицы.

Соответствие X9/X11 высокочастотной паре и X10/X12 низкочастотной паре
подтверждается описанием [стенда](../../docs/stand.md). Внешняя часть
с четырьмя SA612 не полностью отражена основной схемой. Названия цепей
на рисунке не заменяют проверку соединений, QSF и `pin-lock.json`.
