Файлы скопированы из материалов владельца без изменения содержания;
имена нормализованы для устойчивых ссылок. Полноразмерные JPEG сохранены
без перекодирования. Сведения об авторе в метаданных фото сохранены;
координаты GPS в EXIF не обнаружены.

Основная схема не включает внешнюю часть с четырьмя SA612. Описание связи
с фотодиодами основано на подтверждении владельца и стендовых проверках.
Это комплект схем и спецификации, а не полный производственный комплект:
редактируемые CAD/PCB-файлы и Gerber в этой папке отсутствуют.

| Разъём | Сигнал в последней серии |
|---|---|
| X9 / RIGOL CH1 | Опорный ВЧ после смесителя |
| X10 / CH2 | Опорный НЧ после смесителя |
| X11 / CH3 | Отражённый ВЧ после смесителя |
| X12 / CH4 | Отражённый НЧ после смесителя |
| X17–X20 | Соответствующие цифровые сигналы после компараторов |
| X5 | UART к USB–TTL, 3,3 В, 115200 8N1 |

Направление разностей — отражённый минус опорный: CH3−CH1, CH4−CH2.
Номера аналоговых входов не совпадают с номерами выходов DDS.
Выводы FPGA определяет проверенный [QSF](../fpga/DistanceSensorFpga_v0.qsf).
